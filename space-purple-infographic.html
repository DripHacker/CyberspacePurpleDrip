01

What this project is

Cyberspace Purple Drip is a pure declarative VS Code extension (a fork of zzAIMoo's Space Purple) — there is no compiled code, no TypeScript, no runtime. It's a manifest plus two big JSON color maps. VS Code reads them and repaints itself.

🎨It's just colors

The entire extension is data. Two theme files assign hex colors to ~140 UI elements and ~150 syntax token scopes each. No logic runs.

🌗Two moods

Cyberspace Purple Drip Dark (cosmic violet canvas) and Cyberspace Purple Drip Light (soft lilac canvas), registered through the contributes.themes array.

📦How it ships

Packaged with vsce package and pushed to the Marketplace with vsce publish — automated by publish.bat.

02

Anatomy of a theme file

Each themes/*.json file is built from four blocks. Together they cover everything you see — from the title bar down to a single Rust lifetime token.

1

"colors" ~140 keys · the workbench

Paints VS Code's chrome: editor & sidebar backgrounds, status bar, tabs, buttons, scrollbars, the terminal's 16 ANSI colors, git decorations, peek views, notifications. This is where the purple "space" lives.

2

"tokenColors" ~150 rules · TextMate syntax

The classic syntax highlighter. Each rule maps a TextMate scope (e.g. keyword.control, entity.name.function) to a foreground color and optional italic/bold. Covers 25+ languages explicitly.

3

"semanticTokenColors" 3 keys · compiler-aware

Overrides driven by the language server's real understanding of code. Here it refines enumMember, variable.constant and variable.defaultLibrary beyond what plain regex scopes can tell apart.

4

"name" / "type" metadata

Display name and the base type (dark or light) that tells VS Code which defaults to fall back on for anything the theme doesn't explicitly set.

07

Quirks & things worth knowing

Honest notes from reading the source — small oddities and asymmetries between the two files.

🟢

A stray neon-green leftover in the dark file

The dark theme opens with a non-standard "rules": [ { "": "#00FF00" } ] block carrying the comment "green ← this is the property! background of right part (scrollbar)". The empty key means VS Code ignores it — it's an author's experiment that never got cleaned up. Harmless, but not real config.

🎚️

The dark file has more syntax detail

The old C#-only Ice #B1E4EE / Cyan #68BDCE locals and fields are gone — those scopes now share the same Amber / White / Rose set as everything else. Light still collapses more of that into its red variable color. Dark remains the more carefully tuned variant — the README even notes Light is still being updated.

🟦

One teal hides in an all-purple UI

The dark workbench is wall-to-wall purple except for a recurring teal #23655f — used for word-highlight, code folding, the list-filter widget and merge "current" blocks. It's the deliberate cool contrast against the warm violet.

🔁

Two purples do the talking

Functions use #ca72ec while keywords use #e353cd — close cousins that are easy to confuse at a glance. Rust's support.function.std is a near-duplicate at #d272ec.
