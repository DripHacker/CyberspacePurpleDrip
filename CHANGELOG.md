## [Fork] - 2026-06-01

### Changed
- Renamed the project to **Cyberspace Purple Drip** — display name, both
  theme-picker labels (`Cyberspace Purple Drip Dark` / `Light`), the theme
  `name` fields, and the package identifier (`space-purple` → `cyberspace-purple-drip`).
- Kept **zzAIMoo** as `author` in `package.json`; **DripHacker** listed as contributor and set as `publisher` of this fork build.
- **Dark theme:** active title bar is now Cosmic Canvas (`#3b205a`, was Void `#1f152a`).
- **Dark theme:** inactive title bar is now Nebula Surface (`#2f1849`, was `#3b205a`).
